# 오션중학교 학부모 공개수업 안내 사이트

GitHub Pages에서 바로 운영할 수 있는 정적 HTML 사이트입니다.

교실 찾기 결과의 `지도에서 위치 보기`를 누르면 선택한 교실이 있는 층의 배치도만 크게 표시됩니다.
선택한 교실은 배치도 위에서 파란색 원과 교실명 말풍선으로 깜빡이며 표시됩니다.
배치도 위 안내판과 위치 말풍선에는 층 정보가 크게 표시됩니다.
온라인 참관록의 과목은 선택한 학반의 5·6교시 과목만 드롭다운에 표시됩니다.

## 1. 수업 시간표 입력

2026학년도 가정통신문의 1~3학년 1~10반 5·6교시 과목과 교실을 `script.js`의 `rawTimetable`에 반영했습니다. 행사 전에 변경된 내용이 없는지 확인하고, 확정된 수업 주제가 있다면 `topic` 값을 교체합니다.

```js
"1-1": [["기가", "1-1 교실"], ["수학", "1-1 교실"]]
```

## 2. Google Sheet 연동

1. 새 Google Sheet를 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. `google-apps-script/Code.gs` 내용을 붙여넣고 저장합니다.
3. **배포 → 새 배포 → 웹 앱**을 선택합니다.
4. 실행 사용자는 `나`, 액세스 권한은 `모든 사용자`로 설정하고 배포합니다.
5. 발급된 웹 앱 URL은 현재 `script.js`의 `GOOGLE_SCRIPT_URL`에 입력되어 있습니다.
6. 테스트 제출 후 시트에 `참관록` 탭과 행이 생성되는지 확인합니다.

> 웹 앱 코드를 바꾼 경우에는 반드시 **새 버전으로 다시 배포**해야 합니다.

## 3. GitHub Pages 배포

1. 새 GitHub 저장소에 이 폴더의 파일을 업로드합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. Source에서 **Deploy from a branch**, Branch에서 **main / (root)**를 선택합니다.
4. 표시된 공개 주소로 접속해 확인합니다.

## 운영 전 확인

- 상단 날짜 문구가 실제 행사 일정과 일치하는지 확인
- 첨부 안내문에 층이 따로 표기되지 않은 일반 교실은 `1학년=본관 2층`, `2학년=본관 3층`, `3학년=본관 4층`으로 표시되므로 실제 배치와 대조
- 안내문에 없던 수업 주제를 확정 자료에 맞게 입력
- Google Sheet 시험 제출 및 모바일 화면 확인
- Google Sheet의 공유 설정은 비공개로 유지 가능하며, Apps Script 웹 앱만 제출을 받습니다.
